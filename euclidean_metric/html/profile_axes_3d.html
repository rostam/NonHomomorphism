Graphs as axes

Pick three test graphs T. Each graph G is placed at (φX(G), φY(G), φZ(G)), where φT(G) = α(T,G)/e(T) is the fraction of T's edges that must be deleted before T maps into G. A coordinate is 0 exactly when T → G. Each coordinate takes only a few values, so many graphs share a point. "Spread stacked points" adds a small offset so you can see them; the highlighted families stay at their exact positions.
